📜 Свод правил

СВОД ПРАВИЛ:
1. Основные правила:
1.1 Все обязаны соблюдать правила;
1.2 Незнание правил не освобождает от бана;
1.3 Главная Администрация вправе наказать игрока по любой причине;
1.4 Главная Администрация может перенести Вайп на любое время;
1.5 Только Главная Администрация может корректировать свод правил;
1.6 Оскорбление, провоцирование команды запрещено;
1.7 Администратор может вызвать игрока на проверку без объяснений;
1.8 Администрация не обязана общаться с игроками без причины;

2. Правила чата:
2.1 Запрещена нецензурная лексика;
2.2 Запрещено оскорбление и унижение игроков;
2.3 Запрещён Капс, Спам, Флуд;
2.4 Оскорбление родственников игроков запрещено;
2.5 Запрещается розжиг межнациональной розни и расизм;
2.6 Запрещено вызывать игроков на проверку читов;
2.7 Запрещено покупать игровые ценности за реальные деньги;

3. Игровые правила:
3.1 При жалобе нужно показать запись и указать ник нарушителя;
3.1.1 Ложные показания могут привести к бану;
3.2 Запрещено использование читов, кликеров, автокликеров;
3.2.1 Читы могут использоваться только для античита с разрешения админов;
3.2.2 Запрещённые модификации могут быть разрешены определённой группе;
3.3 Запрещено помогать нарушителям;
3.4 Запрещено обрушение сервера или вызов лагов;
3.5 Решение спорных ситуаций за Главной Администрацией;
3.6 Запрещено использовать баги сервера;
3.7 Ограничение размера клана/команды: 4/5 игроков;
3.8 Один игрок не может иметь несколько аккаунтов одновременно.

4. Аккаунт:
4.1 Ник не должен быть похож на ник Администрации;
4.2 Ник не должен быть похож на другие проекты или чит-клиенты.
