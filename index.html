📜 Свод правил

СВОД ПРАВИЛ:
1. Основные правила:
1.1 Все обязаны соблюдать правила;
1.2 Незнание правил, не освобождает от бана;
1.3 Главная Администрация, вправе наказать Вас по причине, не указанной в правилах;
1.4 Главная Администрация может задержать Вайп, перенести Вайп на любое время;
1.5 Только Главная Администрация имеет право корректировать данный свод правил без уведомления игрока;
1.6 Оскорбление, провоцирование команды проекта запрещено.
1.7 Любой Администратор вправе вызвать игрока на проверку без объяснений.
1.8 Администрация не может общаться с игроками без веской причины.
2. Правила чата:
2.1 Запрещена нецензурная лексика;
2.2 Оскорбления игроков запрещены;
2.3 Капс/спам/флуд запрещен;
2.4 Оскорбления над родственниками игроков — повод для бана;
2.5 Запрещен расизм и межнациональные конфликты;
2.6 Запрещено вызывать игроков на проверку читов;
2.7 Покупка игровых ценностей за деньги запрещена.
3. Игровые правила:
3.1 Требуется доказательство нарушений (видео и ник нарушителя).
3.2 Читы и автоматизация запрещены;
3.3 Запрещено помогать нарушителям;
3.4 Запрещены действия, нарушающие работу сервера;
3.5 Спорные ситуации решает Администрация;
3.6 Запрещено использовать баги сервера;
3.7 Кланы и команды ограничены;
3.8 Один игрок — один аккаунт.
4. Аккаунт:
4.1 Ники Администрации не копировать;
4.2 Ники других проектов/чит-клиентов запрещены.
